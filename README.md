## 🍯 Experience

### AI 金融产品 · 公司匿名

- **专业场景产品化**：将投行估值、一级市场、基金研究和卖方研究流程转化为可执行、可评测的 Agent 任务。
- **评测生产流程**：参与搭建材料采集与脱敏、任务合成、标准答案构建、Rubrics 设计、对抗质检与交付验收的自动化管线。
- **动态建模质量**：通过工作簿公式重算、关键估值节点校验及 Agent-as-a-Judge 评分，检验数据甄别、财务推理与动态建模能力；结合专家复核与修复回归，提升可解性、公平性与可复现性。
- **持续协作评测**：将单轮任务拓展为多轮工作流，覆盖需求变更、上下文积累、约束冲突和任务切换，关注从过程到最终交付的质量。
